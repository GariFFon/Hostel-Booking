# Hostel Booking

Multi-hostel / PG booking marketplace.

- `backend/`  Next.js API-only service (PostgreSQL, Redis, Cloudinary)
- `frontend/` Next.js reference website (consumes the backend API)
- Mobile app lives in the sibling repo `Hostel-Booking-App` (Flutter) and uses the same API.

See [docs/runbook.md](docs/runbook.md) to run locally and [docs/architecture.md](docs/architecture.md).
